Công cụ định dạng SQL

Định dạng và làm đẹp câu lệnh SQL dễ đọc hơn

Công cụ giúp sắp xếp và trình bày câu lệnh SQL rõ ràng, dễ đọc. Hỗ trợ 7 hệ quản trị cơ sở dữ liệu: SQL tiêu chuẩn, MySQL, PostgreSQL, SQLite, BigQuery, Snowflake và T-SQL. Dán câu lệnh, chọn hệ quản trị rồi định dạng, rút gọn, sao chép hoặc tải kết quả về máy.
